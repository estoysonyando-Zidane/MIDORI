# 根拠の扱い

## 三つを混ぜない

| | 何か | 例 | 扱い |
|---|---|---|---|
| **FACT** | 一次資料が言っている | 国土地理院の測量外形、省令の寸法、日付入りの写真 | そのまま使う |
| **INFERENCE** | 資料から筋道立てて導いた | 1/25,000で単線＝二条の岸を持つ幅に達しない→3.6m | 導出過程ごと記録 |
| **MEMORY** | そこにいた人が覚えている | 「駅を出たら道が正面にあった」 | **捨てない。証拠と別枠で持つ** |

記憶は「証拠として弱い」から捨てるのではない。**体験の忠実度(Experiential
Fidelity)の主要な情報源**であり、地図には残らないものを唯一持っている。
ただし FACT と同じ欄に書かない。

## 確度は地物ごとではなく、地物の**部分**ごと

一つの地物が、部分によって別々の確からしさを持つ。

```json
"detail_confidence": {
  "existence":  "B (official_record — 省令解釈基準 第54条関係4)",
  "position":   "C (inference — ホーム端から8m。実際の建植位置は文献に無い)",
  "appearance": "C (第55条の図による三位式色灯。灯の寸法は同備考の下限であって実測ではない)"
}
```

信号機は「在ること」が official_record で「どこに在るか」が inference。
これを一つの confidence に潰すと、どちらの意味かが失われる。

## 絶対に守ること

1. **確度を上げない。** 一度 C としたものを、後から「たぶん合っている」で
   B にしない。上げてよいのは新しい資料が出たときだけ。
2. **誤読は消さずに残す。** 読み違いが分かったら直し、**古い読み取りが誤り
   だったことを出典の記録に書く**。「ストリートビューから色あせた白と読んだ
   ← これは誤読。2018年の写真は鮮やかな青緑」のように。
3. **用途から外見を推定しない。** 郵便局だから郵便局らしい見た目、をやらない。
   検査(`validate-reality-data.mjs` の appearance leak)が捕まえる。
4. **一般論を証拠の代わりに置かない。** 「日本のホームの縁端に青緑はない」と
   書いて実際の色を消した事故がある。一般論は証拠ではない。
5. **造形しないことを選べる。** 遠景地形は1セル243m。そこに堤高73mのダムの
   形を作るのは、地形が持っていない情報を足すこと。座標だけ記録して造形しない
   のは、立派な答え。

## 取り込みスクリプトは手作業を消す

`import-gsi-town.mjs` は `BLDG_GSI_*` を**全消ししてから入れ直す**。
その後の `import-gsi-labels.mjs` と `identify-midorinoyu.mjs` が付け直している
同定（緑の湯・郵便局・駐在所）は、**単独実行で黙って消える。**

実際に起きた事故: 緑の湯が22m離れた131m²の小屋に紐付いていた。正しくは590m²。

→ **順番は `scripts/README.md` にある。第2段は 1→7 を通しで走らせる。**
→ 再生成の前に、何が消えるかを数える。`自動再生成データ ≠ 正解`。

## World の外にあるもの

意図して範囲外にある地物は `outside_world: true` を宣言する。境界検査は
警告ではなく別枠で数える — **黙らせるのではなく数える**。
逃げ道には天井がある（遠景地形の届く35km）。それを超えたら座標の誤りを
庇っているので警告が戻る。

## 判断に迷ったとき

- 二つの資料が食い違う → **両方を記録し、採らなかった理由を書く。**
  雑なトレースで当事者の証言を覆さない。
- 資料が無い → **無いと書く。** `U` は正当な値。
- 測れない → 測ろうとした方法と、なぜ足りなかったかを残す。
  「シームレス写真は2m/画素、1974年の空中写真もz=17で限界、
  レール検出は道床の粒に負けた」は次の人への贈り物。
